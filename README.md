📊 Sales Analysis Dashboard | Power BI

An interactive Sales Analysis Dashboard created in Microsoft Power BI to analyze sales performance, revenue, profit, products/categories, customer segments, regions, cities, and trends over time.

🚀 Project Overview

The goal of this project is to transform raw sales data into a professional and easy-to-understand business intelligence dashboard.

The dashboard provides a high-level view of business performance and allows users to explore sales data using interactive filters and visualizations.

🎯 Project Objectives

Analyze overall sales and profit performance

Compare sales across different regions

Identify high-performing cities

Analyze sales by category and segment

Track sales and profit trends over time

Monitor key business KPIs

Present data through an interactive and professional dashboard
